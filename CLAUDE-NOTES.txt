## Hatch Research — CLAUDE NOTES
Last updated: 2026-08-23

## Project Overview
Two-component stock research tool for NASDAQ/NYSE shares tradeable via NZ's Hatch platform:
1. hatch-research (this repo) — scan.py Python scanner + GitHub Actions automation
2. hatch-mobile — web app hosted on GitHub Pages (separate repo)

## Repos
- Scanner: https://github.com/meganwood321/hatch-research (PUBLIC)
- Web app: https://github.com/meganwood321/hatch-mobile (PUBLIC)
- Live app: https://meganwood321.github.io/hatch-mobile/

## Current State
### scan.py
- Scans S&P 500 + S&P 400 + NASDAQ 100 (~900 tickers)
- 8 parallel workers, retry with backoff
- Saves scan_results.json + scan_results.csv
- Run with: python scan.py
- OR double-click Run Scan.bat

### GitHub Actions (.github/workflows/scan.yml)
- Runs automatically every weekday at 6pm UTC (7am NZT)
- Commits scan_results.json + scan_results.csv back to repo
- Can be triggered manually from GitHub Actions tab
- Web app fetches results from raw.githubusercontent.com

### Hatch Mobile web app (separate repo: C:\ClaudeProjects\Hatch Mobile)
- Two tabs: Value Screen (default, left) + Stock Lookup (right)
- Value Screen auto-fetches scan_results.json from GitHub on open
- Filters split into Business Quality + Valuation & Pricing groups
- Staleness warning if data >3 days old on a weekday
- Score sync: Lookup tab uses yfinance scan score when available
- Warns when looked-up ticker was not in last scan
- Responsive: 2-col filter grid on mobile, auto-expand on desktop
- Title: "Stock Research · NASDAQ & NYSE"

## Scoring System (100pts total)
- Business Quality (35): FCF margin, ROE, revenue growth, net margin
- Financial Strength (20): D/E ratio, current ratio, FCF positive
- Valuation (25): PEG, forward P/E, P/B, trailing P/E
- Analyst Sentiment (20): upside to target, 52wk position

## APIs
- Finnhub: free key needed, saved in localStorage in web app
- yfinance: no key needed, used only in scan.py

## Key Files
- scan.py — lean scanner script
- Run Scan.bat — double-click launcher (also on Desktop)
- .github/workflows/scan.yml — GitHub Actions workflow
- scan_results.json — output consumed by web app (also committed by Actions)
