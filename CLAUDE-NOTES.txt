# Hatch Research - Claude Notes

## Project Overview
Stock research web app for NASDAQ & NYSE shares (traded via Hatch platform NZ). Scores stocks on fundamentals weighted by research-backed predictive strength. Supports manual ticker lookup, side-by-side comparison, and full exchange scanning.

## Current State (2026-04-07)
- v1.2: added news sentiment analysis feature
- Flask app on localhost:5001
- yfinance for all stock data (no API key needed)
- **Curated ticker universe**: S&P 500/400/600 + Russell 1000/2000 fetched
  from Wikipedia via pandas.read_html, cached 7 days in
  cache/curated_tickers.json (~2500 tickers). Falls back to embedded list
  if Wikipedia fetch fails.
- **Parallel scanning**: ThreadPoolExecutor with SCAN_WORKERS=10
- **Skip recommendations during scan**: halves per-ticker fetch time; full
  data (incl. analyst recs) is still fetched for lookup/compare routes
- **Ineligibility cache**: cache/ineligible.json tracks tickers known to be
  below $300M mcap / 100k volume, 30-day TTL. Subsequent scans skip these.
- **News Sentiment**: FinBERT-powered sentiment analysis on Finnhub articles.
  Shows overall sentiment, daily trend chart, source breakdown, and
  article list with per-article scores. Triggered on ticker lookup or via
  "News" button in results table. Cached 6 hours per ticker.
  - Relevance filter: drops articles that don't mention the ticker/company
  - Article links use Google search (Finnhub free tier URLs are broken)
  - Falls back to keyword-based sentiment if FinBERT not available
- 24-hour cache for stock data in cache/ folder

## Scoring System (100 points max)
Weighted by research-backed predictive strength:
- **Business Quality (35 pts)**: FCF margin (12), ROE (12), revenue growth (8), profit margin (3)
- **Valuation (25 pts)**: PEG (10), forward P/E (8), P/B (4), trailing P/E (3)
- **Financial Strength (20 pts)**: D/E (8), current ratio (6), FCF positive (6)
- **Market Sentiment (20 pts)**: analyst buy% (8), price vs target (6), 52-wk position (6)
- Dividends, beta, payout ratio shown but not scored (weak predictors)

## Hatch Eligibility Filters
- Market cap > $300M USD
- Average daily volume > 100k shares
- Listed on NASDAQ or NYSE

## Data Sources
- yfinance (Yahoo Finance): all fundamentals, analyst data, price data. No API key.
- Finnhub (optional): full exchange ticker lists. Free key, 60 req/min, no daily cap.
